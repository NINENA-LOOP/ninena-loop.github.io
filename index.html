9NA GameDuB TH

อ่านซับอังกฤษในเกม → แปลไทย → พากย์ออกลำโพงทันที

⬇ ดาวน์โหลดฟรี

สำหรับ Windows 10/11

⚠️ แจกฟรีเท่านั้น ห้ามนำไปขาย — ถ้าคุณจ่ายเงินซื้อโปรแกรมนี้มา แปลว่าคุณโดนหลอก

วิธีใช้

  1. แตกไฟล์ zip แล้วเปิด 9NA GameDuB TH.exe (ถ้า Windows เตือน ให้กด More info → Run anyway)
  2. ใส่ key ของ Claude — ขอได้ที่ console.anthropic.com
  3. กด ⛶ เลือกพื้นที่ซับ แล้วลากคลุมบริเวณที่ซับในเกมขึ้น
  4. พิมพ์ชื่อเกมที่เล่น
  5. กด ▶ เริ่มพากย์ หรือกด F9

ค่าใช้จ่าย

โปรแกรมฟรี แต่ค่าแปลผู้ใช้จ่ายเองผ่าน key ของ Claude (คิดตามที่ใช้จริง) · เสียงพากย์ Edge ฟรี · เสียง ElevenLabs ใส่ key เองได้ ไม่บังคับ
