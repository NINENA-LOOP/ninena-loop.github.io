คำถามที่พบบ่อย

 

ฟรีจริงไหม?

ตัวโปรแกรมฟรี 100% ไม่มีเวอร์ชันเสียเงิน สิ่งที่ต้องจ่ายมีแค่ค่าแปลของ Claude ซึ่งคุณจ่ายตรงให้ Anthropic ตามที่ใช้จริง

ทำไม Windows ขึ้นเตือนตอนเปิด?

เพราะโปรแกรมไม่ได้ซื้อใบรับรองการเซ็นโค้ด (มีค่าใช้จ่ายรายปี) Windows จึงไม่รู้จักผู้พัฒนา กด More info → Run anyway ได้เลย และดาวน์โหลดจากเว็บนี้เท่านั้น

ประหยัดค่าแปลยังไง?

ตั้งคุณภาพคำแปลเป็น "เร็ว" (ถูกที่สุด) ปิด "แปลเร็วพิเศษ" ไว้ และใช้รุ่นสรุปแบบ "ประหยัด"

แอพบอกว่าไม่มี "ชุดอ่านตัวหนังสือภาษาอังกฤษ"

กด "ใช่" แอพจะติดตั้งให้ (ฟรีจาก Microsoft) เสร็จแล้วเปิดแอพใหม่

เจอปัญหา แจ้งได้ที่ไหน?

กดปุ่ม "โฟลเดอร์ log" ในแอพ แล้วส่งไฟล์ gamedub.log มาทางช่องทางของ NINENA LOOP ด้านล่าง (ห้ามส่งไฟล์ keys.env)

พร้อมดำดิ่งแล้วหรือยัง?

โหลดฟรี เล่นเกมโปรดด้วยเสียงพากย์ไทย
